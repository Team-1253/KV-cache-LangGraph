공통 인덱스가 아니라 **기술별 네임스페이스로 분리**해 각각 top-k를 뽑습니다
(`rag/retriever.py`). 공통 풀이면 분량이 많은 DeepSeek-V2가 검색을 잠식합니다.

## 주의: 코퍼스 내 수치 충돌

`93.3`이 서로 다른 두 맥락에 동시에 존재합니다.

- "KV cache를 **93.3%** 감소" — 우리가 찾는 핵심 수치
- "ARC-Challenge (Acc.) 25-shot … **93.3**" — 무관한 벤치마크 정확도

검색·추출 단계에서 이 둘을 혼동하지 않도록 주의하고, 인용 시 **baseline을 반드시 병기**합니다.
