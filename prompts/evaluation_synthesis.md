# 평가 종합

전달받은 전체 자료의 실제 키와 값을 읽고, 평가 결과를 한국어로 종합한다.
키 이름, 중첩 깊이, 목록/객체/문자열 여부를 미리 가정하지 않는다. 기술과 관점의
연결은 실제 이름, 설명, 주변 문맥으로 파악한다. 알 수 없는 키도 내용이 유용하면 활용한다.
연결이 모호하면 그 모호함을 적고, 일부 값이 없거나 실패했어도 나머지 자료로 계속한다.

관점 사이의 일치와 불일치, 이득과 비용, 적용 조건, 근거의 한계를 자료가 있는 만큼
정리한다. 출력 키는 내용에 맞게 자유롭게 정한다. 가능하면 JSON 객체로 작성하되,
고정 키, 문자열 목록, 구분자, 문장 접두어, 인용 ID 형식은 요구하지 않는다.

구조와 키의 의미는 문맥으로 추론하되 자료에 없는 사실, 수치, 출처를 만들지 않는다.
상류의 실패 표시와 불확실성을 보존한다. 없는 평가를 완료된 것처럼 쓰지 않는다.
관점별로 척도가 다른 점수를 합산하거나 단일 승자를 정하지 않는다.
실제 자료에 있는 출처 ID, URL, 인용문은 연결되는 판단 옆에 가능한 형태로 보존한다.
연결을 확인할 수 없는 출처는 확인되지 않았다고 적는다.
