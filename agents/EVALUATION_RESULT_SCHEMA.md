# 평가 종합과 보고서의 데이터 전달

`evaluation_result`는 자유 형식이다. JSON 객체, 목록, 문자열을 모두 받을 수 있으며
고정 키, 문장 접두어, 구분자, 출처 ID 형식을 강제하지 않는다.
종합 노드는 실제 입력 전체의 키와 값을 읽고 의미와 연결 관계를 파악한다.
JSON 응답은 해석해서 보존하고, JSON으로 해석되지 않는 응답도 원문으로 전달한다.

보고서 노드도 전체 입력을 직접 읽는다. 특정 경로에서 점수나 근거를 추출하거나
문장 형식, 분량, 키 누락을 이유로 결과를 거부하지 않는다.
보고서의 장 구성은 유지하며 각 장에서 쓸 자료는 모델이 실제 내용으로 판단한다.

종합이나 보고서 생성에 일반 예외가 발생하면 `run_errors`에 실패 단계와 예외 유형을
기록하고 계속한다. 상위 그래프의 노드 실행 및 모듈 로딩 실패도 같은 방식으로 처리한다.
보고서의 일부 장이 실패하면 작성 가능한 장을 보존하고 원자료를 부록에 넣는다.
보고서 생성 전체가 실패하면 원자료를 포함한 대체 문서를 `final_report`로 반환한다.

이는 정상 평가 완료를 보장하는 것이 아니라, 실패 정보와 확보된 자료를 끝까지
전달하기 위한 처리다. 사용자 중단, 프로세스 강제 종료, 메모리/시스템 장애까지
실행 완료를 보장하지 않는다. 생성 모델의 요청에는 시간 제한과 재시도 상한이 있다.
